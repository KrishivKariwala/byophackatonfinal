## Context
Vendors re-post manually from templates. The original brief had recurring schedules.

## Scope
- Let a vendor schedule a template to publish daily at a set time with window and quantity.
- Respect the 30% rule, window rules and the safety declaration at each publish.

## Acceptance criteria
- [ ] A schedule publishes on the demo clock.
- [ ] Editing or pausing a schedule works.
- [ ] Tests cover the rules at publish time.
