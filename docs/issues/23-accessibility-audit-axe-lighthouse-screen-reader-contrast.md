## Context
Accessibility was designed in (44 px targets, labels, status roles) but never audited.

## Scope
- Run axe and Lighthouse on every screen in all three languages.
- Test with a screen reader (VoiceOver) on the landing page, sign-in, discover, checkout, pickup pass and the header dropdowns.
- Measure contrast for the tomato, burgundy, peach and cream pairs.

## Acceptance criteria
- [ ] No serious or critical axe violations.
- [ ] Dropdowns announce state and are fully keyboard operable.
- [ ] Contrast meets WCAG 2.1 AA.
