## Context
The Seasons and Chunko Bold are not installed; stand-ins (Cormorant Garamond, Bagel Fat One) render. The supplied filenames contain DEMO.

## Scope
- Obtain the licensed web and commercial files and place them in `public/fonts/` using the names in `reference/font-assets-manifest.md`.
- Confirm the licence covers web and PDF use before public launch.
- Embed them in PDFs if the licence allows.

## Acceptance criteria
- [ ] The official fonts load on every screen.
- [ ] Licence confirmation is recorded in the repo docs.
